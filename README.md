# Parchate
Mapa interactivo de Medellín para la exploración de comunas y barrios.
dia anterior 
dejamos Parchate con el SVG del mapa conectado a JavaScript, corregimos el HTML para que no hubiera IDs duplicados, hicimos que las comunas respondan al mouse y al clic, y conseguimos que al seleccionar una comuna aparezca su nombre y un texto de información debajo del mapa; además, dejamos preparada la selección visual para que una comuna quede resaltada y la siguiente reemplace a la anterior.


Hoy 
avanzamos en el MVP de Parchate, integrando el mapa SVG de Medellín y haciendo interactivas sus comunas mediante JavaScript; agregamos efectos de hover, selección de comunas y una tarjeta que muestra información de cada una, organizamos los datos de las 16 comunas y corregimos errores de estructura y código duplicado en mapa.js, además ajustamos el tamaño del mapa para que tuviera mayor presencia visual y comenzamos a preparar la función “Ver más” para llevar al usuario a una página con información detallada de la comuna seleccionada.
